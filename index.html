ABOUT ME

Hi, I'm John, and I am a game programmer from the North East of England. I've been tinkering with computers since I was 8 years old, and I've just wrapped up development on MiB: Most Wanted as a Gameplay Programmer for Coatsink Software. I hold a Master's in Computer Science and I graduated from Newcastle University.

As mentioned, I've been a professional games programmer at Coatsink for around 6 years, mainly working in the Unity engine with C#. However, in my personal projects I like to use a range of other languages with some notable highlights below:

● C++ Custom lightweight 3D game framework

● C 2D game development for porting accross retro systems

● Java desktop applications for tooling and editors

● Python 2D prototyping using the PyGame framework

● Z80 assembly for the ZX Spectrum

● 6502 assembly for the Atari 2600
